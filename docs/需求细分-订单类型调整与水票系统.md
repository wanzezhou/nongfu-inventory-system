> 水票抵扣含义（按"按进货价抵扣"确认）：正常卖分销价；用水票则按**进货价**收款（水票抵掉了分销价与进货价的差价）。

## 二、直营水站销售计价改造 + 水票系统

### 2.1 计价方式（新建订单时选择，整单二选一）

| 方式 | 说明 | 单价 |
|---|---|---|
| A. 按分销价 | 现有逻辑 | unit_price = 商品档案分销价 wholesale_price |
| B. 水票抵扣 | 整单用水票：每件商品消耗 1 张对应水票 | unit_price = 商品档案**进货价** purchase_price（已确认） |

> 整单二选一：选"水票抵扣"后，整张订单所有商品均按进货价计价，且下单时校验/核销对应水票。

### 2.2 水票定义、持有与发行（返货清单机制）

- **一张水票 = 一件指定商品**（票面绑定商品，只能抵扣该商品 1 件）
- **持有方 = 水站**（水票库存按"水站 + 商品"统计）
- **发行 = 每月返货清单录入**（用户确认）：
  1. 每月直营水站提供返货清单：`水站 + 商品 + 数量 + 返货配送费`
  2. 管理员在**水票管理页**按清单录入：选水站、商品、数量（如 水站1 / 商品A / 3件）→ 系统生成 3 张商品A水票（挂在水站1名下）
  3. 清单中的**返货配送费**单独记录（见下方 ⚠️ 待细化 H）
- ⚠️ 待细化 H：**返货配送费的入账归属**（清单里记录的配送费如何记录/统计）？
  - 选项 1：录入时一并记录为一条"返货配送费"支出记录（可纳入成本统计的固定支出或单独统计）
  - 选项 2：暂不记录，仅水票入库
  - 建议：选项 1（配送费是真实成本，应可统计）

### 2.3 水票使用流程（新建直营水站销售订单，整单二选一）

1. 选客户水站 → 选计价方式：**按分销价** / **水票抵扣**
2. 选"水票抵扣"时：校验该水站可用水票是否覆盖整单（每件商品需有 ≥1 张对应水票），不足提示
3. 下单：整单商品按**进货价**计价 → 水票批量核销（票→已核销，记录订单号）
4. 校验：票商品匹配、票未核销、数量充足

### 2.4 金额与财务口径（关键决策）

| 项 | 水票抵扣件如何处理 | 已确认/建议 |
|---|---|---|
| 订单金额 | 被抵扣件按**进货价**计价收款 | ✅ 已确认（决策点 D） |
| 直营水站销售**营收** | 营收=实收（正常件分销价 + 抵扣件进货价） | ✅ 已确认（决策点 F） |
| 直营水站销售**成本** | 抵扣部分成本照算（货实际出库，进货价） | 建议：照算 |
| **配送费** | 抵扣订单配送费照算（水票只抵货款） | 建议：照算 |
| 库存 | 抵扣订单照常扣库存 | 建议：照扣 |

> ⚠️ 待细化 I：水票抵扣订单的**配送费**：直营水站销售配送费=工人水站配送费，水票抵扣单是否同样收取/计入成本？建议同样（水票只抵货款，不抵配送费）。

### 2.5 数据模型（草案）

```
water_tickets 水票表
  ticket_id      VARCHAR PK       水票编号
  product_id     VARCHAR FK       对应商品
  station_id     VARCHAR FK       持有水站
  status         TINYINT          1-未用 2-已核销 3-作废
  issued_at      DATETIME         发行时间（返货清单录入时）
  issued_by      VARCHAR          发行操作人
  used_at        DATETIME         核销时间
  order_id       VARCHAR          核销关联订单
  remark         VARCHAR

order_items 扩展
  pricing_type   TINYINT 1-分销价 2-水票抵扣（整单级）
  ticket_count   INT     使用水票数（整单=商品数量）

water_ticket_issuance 发行/返货清单记录表（可选，含返货配送费）
  issuance_id    VARCHAR PK
  station_id     VARCHAR FK       水站
  product_id     VARCHAR FK       商品
  quantity       INT              返货/发票数量
  return_delivery_fee DECIMAL     返货配送费（待细化 H）
  month          VARCHAR(7)       所属月份（如 2026-08）
  created_by / created_at
```
