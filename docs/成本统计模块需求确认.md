## 一、模块定位与菜单结构

**一级菜单：成本统计**（放在「营收统计」之后），页面形式参考营收统计：
时间筛选（全部/今日/本周/本月/今年/自定义）+ 汇总卡片 + 明细表格 + 详情 + 按当前筛选导出。

**二级菜单（建议 7 项）**：

| # | 二级菜单 | 对应路由 | 内容 |
|---|---|---|---|
| 1 | 固定支出 | `/cost/fixed` | 房租、水电等仓库固定支出（手动录入） |
| 2 | 线上平台销售成本 | `/cost/platform` | 订单类型 1 |
| 3 | 线下水站分销成本 | `/cost/distribution` | 订单类型 2 |
| 4 | 线下零售成本 | `/cost/retail` | 订单类型 3 |
| 5 | 量贩机供货成本 | `/cost/bulk-machine` | 订单类型 4 |
| 6 | 线下水站返货成本 | `/cost/return` | 订单类型 5 |
| 7 | 零售机供货成本 | `/cost/retail-machine` | 订单类型 6 |

> ⚠️ **与你的确认有 1 处差异需拍板**：你选择"固定支出+营业支出5类共6子项"，但线下零售确认计入后，营业支出已覆盖全部 **6 种订单类型**（1-6）。故菜单为 **固定支出 + 6 类营业支出 = 7 个子菜单**（见上表）。若仍希望 6 项，请说明营业支出 5 类具体指哪 5 类。

## 二、固定支出

### 1. 支出类型（可自定义，类似报销的灵活方式）
- 录入时类型为**下拉选择 + 支持手输新增**：预设 房租/水电/物业费/人工工资/物流运输/设备维护，下拉候选 = 预设 + 历史已用类型（去重）；手输新类型自动进入候选
- 不单独建类型管理页（轻量），后续如需正式类别管理可再拆表

### 2. 录入与管理
- 字段：支出类型、金额（元）、发生日期、备注（选填）、录入人（自动）
- 流程：**直接录入，可修改、可删除**（无审批）
- 汇总卡片：按时间范围统计「各类型支出 + 总支出」；明细列表（分页）按日期倒序
- 导出：按当前筛选（类型 + 时间范围）导出 xlsx

### 3. 数据表（新建）
`fixed_expenses`：expense_id、expense_type、amount、expense_date、remark、created_by、created_at、updated_at
（迁移脚本 `database/migration_add_fixed_expenses.sql` + init.sql 同步）

## 三、营业支出（按订单自动计算，6 类口径）

### 1. 成本口径（单件成本 = 进货价 + 对应配送费，取 order_items 快照字段）

| 订单类型 | 成本 = 进货价 + 【配送费】 | order_items 字段 |
|---|---|---|
| ① 线上平台销售 | 进货价 + 工人零售配送费 | `purchase_price + worker_retail_delivery_fee` |
| ② 线下水站分销 | 进货价 + 工人水站配送费 | `purchase_price + worker_wholesale_delivery_fee` |
| ③ 线下零售 | 进货价 + 工人零售配送费 | `purchase_price + worker_retail_delivery_fee` |
| ④ 量贩机供货 | 进货价 + 工人零售机配送费 | `purchase_price + worker_machine_delivery_fee` |
| ⑤ 线下水站返货 | 进货价 + **水站分销配送费** | `purchase_price + distribution_delivery_fee` |
| ⑥ 零售机供货 | 进货价 + 工人零售机配送费 | `purchase_price + worker_machine_delivery_fee` |

- 单件成本 × 数量 = 该明细行成本；订单成本 = Σ 明细行成本
- **排除已取消订单**（与营收统计一致）
- ⚠️ ⑤返货用 `distribution_delivery_fee`（水站分销配送费）而非工人水站配送费——按你的原话确认

### 2. 明细展示（按订单行）
| 列 | 说明 |
|---|---|
| 订单号 / 订单类型 / 客户 | 复用订单信息 |
| 商品总数量 | Σ 数量 |
| 进货价合计 | Σ(进货价×数量)，分列显示 |
| 配送费合计 | Σ(对应配送费×数量)，分列显示 |
| **成本（总计）** | 进货价合计 + 配送费合计 |
| 下单时间 / 操作（详情） | 详情复用订单详情弹窗 |

- **成本列 hover 拆分**：鼠标移到成本金额（如 ¥100.00）上，tooltip 显示「进货价 ¥90.00 + 配送费 ¥10.00」——分列两字段已单列展示，hover 为汇总提示
- 汇总卡片：当前类型成本合计（按筛选范围）；时间范围切换同营收统计

### 3. 接口
- `GET /api/cost/summary?range&startDate&endDate&orderType` 营业成本汇总（各类型成本，orderType 可选）
- `GET /api/cost/orders?range&startDate&endDate&orderType&page&pageSize` 明细（含 purchase_total / delivery_total / cost）
- `GET /api/cost/fixed-summary` 固定支出汇总
- `GET /api/cost/fixed-expenses`（分页）`POST/PUT/DELETE /api/cost/fixed-expenses/:id`
- `GET /api/cost/export?range&orderType`（营业）/ `GET /api/cost/fixed-export`（固定）
- 计算方式：营业成本纯查询 order_items 计算，**不新建营业成本表**；固定支出新建表
