# 小程序怎么看 —— 手把手（写给非技术同学）

> 目的：让你**亲手打开、亲手点**这套小程序，不用等我截图。
> 全程只有 4 步，第 4 步是唯一需要"填东西"的地方。

---

## 0. 先记住三件事

1. **小程序不在浏览器里看**。它要在「微信开发者工具」里跑（这个是微信官方的免费工具，你已经装好了）。
2. **看之前后端要开着**。后端 = 数据来源。它在本机 `:3000` 端口跑着。重启电脑后要双击项目里的 `start.bat` 把它拉起来。
3. **只需要登录一次**，工具会记住你的设置。

## 3. 两个必须先确认的设置

### ① 勾掉域名校验（必须）

右上角 **「详情」** → **「本地设置」** → 勾选：

> ☑ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

**为什么**：后端现在跑在你自己电脑上（`http://localhost:3000`）。微信默认只允许 https 正式域名，开发阶段必须把这个校验关掉，否则页面全白、接口全报错。上线前会换成正式域名，那时再打开即可。

### ② 确认后端活着

浏览器新开一个标签，访问：

```
http://localhost:3000/health
```

看到类似 `{"code":200,"message":"ok",...}` 就说明后端正常。
看到"无法访问"就是后端没起来 → 双击项目里的 **`start.bat`**，等十几秒再试。

## 4. 登录小程序（唯一要填东西的一步）

左边那块**手机形状的窗口**就是小程序。它会停在登录页（写着「农夫库存管理系统 / 微信订货小程序」）。

**如果看到的是蓝色按钮「微信一键登录」** → 先点页面**最下面那行小字**：

```
切换到本地开发登录
```

然后：

| 填什么   | 值                      |
| -------- | ----------------------- |
| 手机号   | `13900000001`           |
| 身份消歧 | 点开下拉，选 **管理员** |

点 **「开发环境登录」**。

成功后会自动跳到首页，你会看到 **「今日订单」** 和 **「本月经营」** 两个板块。

> **为什么不用「微信一键登录」**：真实的微信登录要求小程序已备案的 https 域名 + 微信支付资质（这部分还在申请中，不受开发进度控制）。开发登录是后端专门留的开发通道，它**只认后台里真实存在的手机号**，不会创建任何假数据。

## 8. 常见问题

| 现象                         | 原因 / 怎么办                                              |
| ---------------------------- | ---------------------------------------------------------- |
| 登录页提示"无法连接后端服务" | 后端没起来 → 双击 `start.bat`，等十几秒                    |
| 页面白屏、接口报错、401      | 第 3 步的「不校验合法域名」没勾                            |
| 提示"本地开发登录未开启"     | 后端 `.env` 里的 `MINI_DEV_LOGIN=1` 被关了（现在是开着的） |
| 提示"匹配到多条记录"         | 登录时「身份消歧」没选 → 选「管理员」                      |
| 首页数字全是 0               | **正常**，见下面第 9 条                                    |
| 提示"该账号已被禁用"         | 这个小程序账号被管理员停用了                               |

## 9. 为什么首页数字大多是 0（重要，别以为坏了）

系统在 9 月做过一次**数据重置**：清掉了所有业务数据（订单、资金流水、水票），只保留主数据：

- 159 个商品 + 159 条库存

所以仪表盘显示 0 **不是坏了，是还没做生意**。界面本身、菜单、能点的功能都是完整可用的。
