# UI 重设计方案 · 红墨留白（沉稳版）

> 日期：2026-09-08
> 范围：农夫山泉经销商进销存管理系统前端 UI 全局重设计

## 一、设计目标

在保留现有布局框架（左侧菜单 + 顶部标题栏 + 内容区）的基础上，将视觉风格从「深色科技感 + 苹果级动效」转为「浅色极简 + 东方水墨意趣」，配色沉稳不刺眼，突出数据本身。

## 二、设计方向

**风格关键词**：宣纸白底、衬线标题、三色点缀（沉稳红/墨绿/暗金）、细边框卡片、墨滴晕染动效。

## 三、设计 Token

### 3.1 配色系统

| 用途 | Token | 值 | 说明 |
|------|-------|-----|------|
| 主背景 | `--bg` | `#F5F4F0` | 暖灰宣纸色 |
| 卡片背景 | `--card` | `#FFFFFF` | 纯白 |
| 主文字 | `--text` | `#1F1F1F` | 近黑 |
| 次级文字 | `--text-2` | `#7A7A72` | 中灰 |
| 辅助文字 | `--text-3` | `#AEAEA5` | 浅灰 |
| 边框 | `--border` | `#E8E6DF` | 暖灰线 |
| **品牌红（主色）** | `--primary` | `#A8201A` | 降饱和深红 |
| 主色浅 | `--primary-light` | `rgba(168,32,26,0.07)` | 悬停背景 |
| 墨绿（辅助） | `--green` | `#2D6A4F` | 成功/正向 |
| 暗金（辅助） | `--gold` | `#A68B3D` | 警告/强调 |

### 3.2 字体

- **标题字体**：`Noto Serif SC`（思源宋体）—— 用于页面标题、卡片数值、logo，营造东方文化质感
- **正文字体**：`Noto Sans SC`（思源黑体）—— 用于正文、表格、菜单，保证可读性

### 3.3 圆角 & 阴影

- 卡片圆角 `14px`
- 微阴影 `0 1px 3px rgba(0,0,0,0.04)`
- 悬停阴影 `0 8px 28px rgba(0,0,0,0.07) + 主色光晕`

## 四、组件设计规范

### 4.1 侧边栏

- 背景：`#FFFFFF` 纯白 + 1px 右侧边框
- Logo：品牌红渐变方块 + 衬线字体标题 + 大字距英文副标题
- 菜单项：
  - 默认：无背景、灰色文字、左侧透明竖线
  - 悬停：主色文字 + `--primary-light` 背景
  - 激活：主色文字 + `--primary-light` 背景 + 左侧 3px 主色竖线 + 加粗
- 分组标题：大写字母 + 大字距（3px）+ 浅灰色

### 4.2 顶栏

- 半透明白底 `rgba(255,255,255,0.75)` + `backdrop-filter: blur(20px)`
- 页面标题：衬线字体 17px 600
- 日期胶囊：暖灰背景 + 细边框
- 用户头像：主色渐变圆形 + 衬线字体首字

### 4.3 统计卡片

- 1px 细边框 + 微阴影，圆角 14px
- 右上角墨色晕染径向渐变（按卡类型变色：红/绿/金）
- 标签：小圆点 + 文字
- 数值：衬线字体 34px 700，小数单位 15px 浅灰
- 底部：趋势百分比 + 进度条（主色→墨绿渐变）
- 悬停：边框变主色半透明 + 主色光晕阴影 + 上移 3px
- 入场：墨滴晕开动画（opacity + translateY + blur）

### 4.4 图表卡片

- 同卡片基础样式
- 底部叠加山水线条 SVG 装饰（主色 3% 透明度）
- 标题衬线字体，徽章主色浅底 + 细边框

### 4.5 表格

- 表头：暖灰背景 + 细下边框 + 600 字重
- 行：细分割线，悬停主色 2% 浅底
- 标签：圆角 6px + 半透明背景 + 细边框（成功用墨绿、警告用暗金）
- 操作按钮：默认灰色，悬停主色 + 主色浅底

### 4.6 按钮（Element Plus 覆盖）

- 主按钮：主色背景，悬停上浮 + 光晕阴影
- 保留光泽扫过效果

## 五、动效系统

- 页面元素错落渐入（`inkSpread` 动画，staggered delay 60-70ms）
- 卡片悬停：上移 3px + 边框高亮 + 光晕
- 菜单：左侧竖线展开 + 文字变色
- 数字：从 0 滚动到目标值（组件内实现）

## 六、实施范围

### 6.1 文件清单

| 文件 | 改动类型 | 说明 |
|------|---------|------|
| `frontend/src/style.css` | 重写 | 全局 CSS 变量 + Element Plus 覆盖 + 动效 |
| `frontend/src/styles/main-layout.css` | 重写 | 侧边栏 + 顶栏 + 内容区布局样式 |
| `frontend/src/views/Dashboard.vue` | 重写 | 仪表盘统计卡片 + 图表样式 |
| `frontend/index.html` | 修改 | 引入 Google Fonts（Noto Serif SC + Noto Sans SC） |

### 6.2 不改动的部分

- 布局结构（侧边栏 + 顶栏 + 内容区的 DOM 结构）
- 路由、菜单配置（menuConfig.js）
- 业务逻辑（API、数据处理）
- 其他业务页面的模板结构（仅通过全局 CSS 覆盖统一样式）

### 6.3 兼容性

- Element Plus 组件样式通过 CSS 变量 + `:deep()` 覆盖
- 保留 `prefers-reduced-motion` 降级
- 窄屏适配规则不变

## 七、验收标准

1. 全站配色符合 Token 定义（主色 `#A8201A`、墨绿 `#2D6A4F`、暗金 `#A68B3D`）
2. 侧边栏白底 + 左侧红竖线激活态
3. 卡片细边框 + 悬停光晕 + 墨滴晕染入场
4. 标题/数值使用衬线字体
5. 前端 `vite build` 通过
6. 仪表盘、表格、对话框、菜单交互正常无报错
